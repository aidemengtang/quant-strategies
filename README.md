# 简单量化策略集（A股 ETF）

三个「够简单、可复现」的策略实现，配一个几十行的回测引擎。数据源用 [akshare](https://akshare.akfamily.xyz/)，**不需要 token、不需要付费数据**，一条命令就能跑出完整回测。

```bash
pip install -r requirements.txt
python run.py --strategy all            # 跑基准 + 双均线 + 动量轮动
python run.py --strategy momentum       # 只跑动量轮动（默认参数）
```

## 回测结果（2015-01-06 ~ 2026-11-06，单边成本万 5）

| 策略 | 年化收益 | 年化波动 | 夏普 | 最大回撤 | 年化换手 |
|---|---:|---:|---:|---:|---:|
| 买入持有 510300 沪深300ETF | 3.13% | 26.3% | 0.12 | -53.0% | — |
| 双均线 MA10/MA30 择时 | 2.95% | 17.3% | 0.17 | -40.3% | 896% |
| 双均线 MA20/MA60 择时 | -2.02% | 17.1% | -0.12 | -51.4% | 524% |
| **ETF 动量轮动（250 日 / 前 3 / 月调仓）** | **11.44%** | **15.3%** | **0.75** | **-22.6%** | 347% |

> 复现命令：`python run.py --strategy all`。数字随数据更新会小幅变化（akshare 前复权价会因分红调整）。
> 动量策略区间为 2016-01-29 起（需 250 个交易日预热），双均线与基准从 2015-01-06 起。

## 一、ETF 动量轮动 `strategies/etf_momentum.py`

**逻辑**（每月最后一个交易日收盘执行）：

1. 池子 6 只宽基/大类 ETF：`510300 沪深300`、`510500 中证500`、`159915 创业板`、`518880 黄金`、`511010 国债`、`513100 纳指`；
2. 打分：`过去 250 个交易日涨幅`（≈12 个月动量，学术上的标准窗口）；
3. 只留分数 > 0 的（绝对动量过滤，全为负则空仓持现金）；
4. 取前 3 名等权，持有到下个月末再平衡。

**为什么是它**：标的少、无个股黑天鹅与退市风险、月度调仓换手可控、不需要成分股或财务数据，因此**没有幸存者偏差**（这 6 只在 2015 年都已上市）。

持仓分布（2015-2026 各月占比）：纳指 76%、黄金 64%、国债 44%、创业板 38%、沪深300 34%、中证500 28%。

⚠️ **必须知道的局限**：

- 2015-2026 这十年恰好是「A 股弱、美股科技与黄金强」的格局，策略收益**很大程度来自这个宏观背景**，不能线性外推；
- `513100` 是 QDII，场内价格有溢价/折价，实盘要避开高溢价时段买入；
- 池子是我人为选的 6 只（有选择偏差）。想更中性，可以换成风格更均衡的池子重跑。

## 二、双均线择时 `strategies/ma_timing.py`

`MA20 > MA60` 满仓、否则空仓，标的是 510300。

结论：**在沪深300上，2015-2026 的择时基本无效** —— MA20/60 年化 -2.0%、回撤仍有 -51%，MA10/30 勉强与买入持有持平但换手 896%。A 股宽基的震荡市里均线反复被打脸，交易成本吃掉全部收益。

这个策略留在仓库里是**当对照组用的**：任何新策略都应该先跑赢它，再谈有没有 alpha。

## 三、回测引擎 `qs/engine.py`

约定（为了不产生未来函数）：

- 权重表 `date=t` 表示「t 日收盘完成调仓」，收益从**下一交易日**开始计入；
- 未分配权重的部分按现金处理，收益记 0（不计利息，保守）；
- 调仓当日按 `Σ|目标-当前|` 收单边手续费；
- 每日按固定权重计算组合收益（等价于每日再平衡到目标权重，多资产场景略偏乐观）。

已用向量化公式 `nav = Π(1 + w.shift(1) · r)` 交叉验证过引擎输出（完全一致）。

## 结构

```
qs/data.py            akshare 取数 + 本地 parquet 缓存（首次跑完，之后离线可跑）
qs/engine.py          逐日撮合 + 绩效指标（年化/波动/夏普/回撤/卡玛/换手）
strategies/etf_momentum.py   策略一：动量轮动
strategies/ma_timing.py      策略二：双均线择时（对照组）
run.py               命令行入口
```
