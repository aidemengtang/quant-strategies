## 1. 「高收益」的量化定义（不许自己另立标准）

"高收益"在这个任务里 = **扣费后的复合年化（CAGR）**，且必须同时满足下表。只提高收益、把回撤放到 -50% 的不算合格——那是加风险不是加 alpha。

主口径：单边成本 **万 5**，全样本区间 **2016-01-01 ~ 2026-11-07**。

| 指标 | 及格线 | 优秀线 |
|---|---:|---:|
| 全样本年化收益 | ≥ 13.0% | ≥ 18.0% |
| **样本外**年化收益（2022-01 起） | ≥ 10.0% | ≥ 15.0% |
| 夏普（CAGR/年化波动） | ≥ 0.85 | ≥ 1.10 |
| 最大回撤 | ≥ -30% | ≥ -22% |
| 卡玛（CAGR/\|MDD\|） | ≥ 0.50 | ≥ 0.80 |
| 年化双边换手 | ≤ 700% | ≤ 450% |
| 成本千 2 时年化 | > 0% | ≥ 8% |

达不到"及格线"就如实写进报告的「结论：未达成」，**不要通过调参硬凑**。诚实的不及格 > 假的高分。

## 2. 硬性红线（违反任意一条，整个交付作废）

1. **未来函数零容忍**。`date=t` 的权重只能用 `≤ t` 收盘及之前的数据算出；收益从 `t+1` 日起计。任何 `shift(-n)`、`center=True`、全样本 `mean()/std()/max()` 标准化都算违规。
2. **不许改 `qs/engine.py`**。新策略必须复用现有引擎和成本模型。理由是：引擎一旦为新策略放宽假设，所有对比都失效。
   （`qs/data.py` 允许改，例如修缓存 key，但不得改变 `load_panel` 的返回语义。）
3. **不许改已有策略的 `build_weights` 行为**，包括默认参数。它们是对照组。
4. **不许用杠杆**。任一日 `weights.sum(axis=1) > 1.0 + 1e-9` 即违规（现金收益记 0，不许假设货币基金收益）。
5. **不许用会被事后修正/事后才知道的数据**：指数成分股名单、基金规模、评级、财报（除非明确用公告日对齐）、"未来会上市的标的"。只允许用**行情类**数据（OHLCV）与其派生量。
6. **不许有幸存者偏差**。新加入池子的标的，其数据在**回测起点（2016-01-01）之前**就必须存在；否则从该标的的数据首日起才允许被选中，并在报告里列出每只的 `数据起始日`。禁止"事后挑 2020 年上市、恰好涨得好的品种"。
7. **样本外只跑一次**。参数选择只允许使用 2016-01-01 ~ 2021-12-31（下称 IS）。定稿后用 2022-01-01 起跑**一次** OOS，结果原样进报告。跑完再改参数 = 作弊，视为作废。
8. **不许 hardcode 收益**。禁止把某段区间的收益当常数写入、禁止 `if date > '2020-03-01': w = ...` 这类按日期打补丁的写法（人工择时规则必须写成可解释的信号，且对全样本一致生效）。

## 3. 标的池

允许扩池到 **12~20 只**，覆盖：A 股宽基（300/500/1000/创业板/科创）、跨境（纳指/标普/日经/德国/恒生/恒生科技）、商品（黄金/白银/原油/豆粕/有色）、债券（国债/短融/十年国债）。

要求：

- 池子里的每只都必须给 `code, name, 类别, 数据起始日`，写进报告附录表；
- 数据起始日晚于 2016-01-01 的，**必须**在 `build_weights` 里天然处理（该标的在无数据期不参与打分，不给权重），不许前向填充；
- 池子定义写成 `strategies/<name>.py` 顶部的常量，便于别人改；
- 扩池会拉新数据，取数走 `qs/data.py` 的缓存机制。**注意本机网络**：进程必须带 `no_proxy='*' NO_PROXY='*'`，否则 requests 会走一个不存在的系统代理直接 SSLEOFError。

## 4. 必须实现的两个候选（同框架对比，二选一主推）

不要只交一个策略。请实现 **A、B 两个候选**，用同一引擎、同一区间、同一成本跑一张对比表，然后选一个主推。选择依据**只能用 IS 段**。

### 候选 A：稳健型 —— 风险平价 + 趋势过滤

- 打分仍用中期动量（如 120/250 日），但**权重不搞等权**，改用波动率倒数（inverse-vol）归一，控制单一高波品种独大；
- 加趋势/风险过滤：例如 `close > MA200` 才允许持有风险资产，否则切到债券/黄金/现金；
- 可选加"动量确认"：短窗（20/60 日）方向与长窗一致才给权重。

目标：夏普和回撤优先，年化 13~15% 可接受。

### 候选 B：进攻型 —— 扩池集中 + 状态切换

- 扩池到 15 只左右，动量打分 + 绝对动量过滤，取前 2~3 只**集中**持有；
- 加状态变量：市场宽度（池内正动量标的占比）或池内波动率中位数，据此在"集中持有 top2"和"分散持有 top5 + 债券"之间切换；
- 允许月度或双周调仓，但要带**换手惩罚/缓冲带**（新标的进入前必须超过在持标的若干名次），压住成本。

目标：年化冲 18%+，但 MDD 不许破 -30%。

### 可选加分（不是必须，别为它牺牲主线）

- 把 A、B 按固定比例合成一条净值，看夏普是否提升；
- 加 `--plot` 输出净值曲线（matplotlib，落 `results/`）。

**注意**：不要为了凑收益把两个候选都调成"只在 2020-2021 有效"的形状。参数平原比单点最优值钱。

## 5. 必须做的 6 项验证（缺一项报告不考虑）

| # | 验证 | 做法 | 合格标准 |
|---|---|---|---|
| V1 | IS/OOS 切分 | IS 2016-01~2021-12 选参；OOS 2022-01~2026-11 只跑一次 | OOS 年化 ≥ IS 的 50%，且 ≥ 10% |
| V2 | 参数稳健性 | 对主参数（lookback ±40%、top_n ±1、调仓频率）做邻域网格，报**矩阵**不是单点 | 邻域内 ≥ 70% 的组合年化 > 10%，无"悬崖式"塌陷 |
| V3 | 成本敏感性 | 万 5 / 千 1 / 千 2 三档 | 千 2 下年化仍 > 0 |
| V4 | 分年度/分状态 | 逐年收益表 + 拆成"沪深300 上涨月/下跌月"两组的平均月收益 | 下跌月不亏于 -1%（或明显优于基准），且**没有单一年份贡献 > 全样本累计收益的 60%** |
| V5 | 集中度与尾部 | 单标的最大平均权重、剔除最好的 3 个月后的年化 | 剔除后年化仍 > 5%，说明不是靠少数几个月 |
| V6 | 同换手随机对照 | 用相同标的池、相同换手率，随机抽同样数量的标的，跑 200 次取分布 | 策略年化位于随机分布 **95 分位以上**（p < 0.05） |

V6 是防"其实只是 beta/运气"的关键，**不要跳过**。实现成 `research/placebo.py` 或脚本内函数均可，但要能在报告里贴出分布图/分位数。

```

run.py                          新增 --strategy high / candid_a / candid_b，默认参数可一键复现
reports/high_return.md          回测报告（模板见第 7 节）
results/<name>_nav.csv          净值序列（date, nav）
results/<name>_weights.csv      权重序列（date × symbol）
README.md                       在结果表里加一行新策略 + 链接到 reports/high_return.md
```

**签名兼容**：`build_weights(symbols=None, lookback=..., top_n=..., start=..., end=...) -> (rets, weights)`，其中 `rets` 是日收益面板、`weights` 的行索引是实际调仓日、列是标的代码。这样 `run.py` 和已有测试模式可以复用。

**单元测试至少覆盖**：

1. 未来函数：把 `t` 日之后的收盘价全部 ×1.5，`t` 日及之前的权重不变；
2. 权重约束：每行 `sum ≤ 1+1e-9`，且无负权重；
3. 成本单调：`cost_rate` 越大 nav 越小（严格）；
4. 与向量化公式 `Π(1 + w.shift(1)·r)` 交叉验证，相对误差 < 1e-9；
5. 边界：数据长度 < lookback、只有 1 只标的、全 NaN 列，都不许抛异常；
6. 无数据泄漏的排名：构造"哪只过去涨得多"的合成数据，断言选中的就是它。

## 10. 反模式警告（这些都是常见作弊，做了等于没做）

- 用全样本的均值/标准差做 z-score 标准化 → 泄漏
- 用"事后涨幅最好"的标的组池子 → 幸存者偏差
- 参数网格扫 200 组，报最好的那组、不报邻域 → 过拟合
- 只在牛市区间回测（2019-2021、2024-2025）→ cherry-picking
- 换手率上千、报告里把成本设成 0 → 成本失真
- 用 `weights` 里塞 1.2 的总仓位模拟杠杆 → 违规
- 报告只写收益不写回撤和最差年份 → 误导
- 把 OOS 结果看到后回头改参数，然后声称"这就是第一次跑的" → 学术不端

如果跑到一半发现"怎么调都到不了 13%"，**就停手，写清楚"在当前数据与成本约束下，ETF 日线级别的月度轮动难以稳定超过 13%，最好成绩 X%，主要瓶颈是 Y"**。这个结论本身有价值，比编一个 30% 的数字有用得多。
