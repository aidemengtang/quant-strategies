## 1. 为什么是可转债（策略的收益来源，写代码前先想明白）

可转债 = 债券 + 转股期权：

- **下有债底**：到期还本付息，纯债价值通常 85~100，价格跌破 90 的债历史上很少亏钱；
- **上跟随正股**：正股上涨 → 转股价值上涨 → 转债价格跟涨（凸性）；
- **不对称收益**：债底封住下行、正股打开上行，这是它长期跑赢纯债、回撤小于股票的结构性原因。

「双低」= 价格低 + 转股溢价率低，就是这个结构的量化表达：价格低给你防守，溢价率低给你进攻。

**回测区间：2018-01-01 ~ 2026-11-07**（2017 年再融资新规后转债才扩容，2018 前样本太少）。
**IS：2018-01 ~ 2022-12（选参）｜OOS：2023-01 ~ 2026-11（只跑一次）**。

OOS 段会经历 2023-2024 转债杀溢价 + 2024 年初信用风险事件，**大概率比 IS 难看，这是预期内的**，不许因此回到 IS 重调。

## 2. 两个候选（必须都实现，同框架对比）

因为**历史溢价率不可得**，两套候选在"溢价率怎么处理"上分野，这本身就是本次实验要回答的问题。

### 候选 A：纯低价 + 正股动量（不依赖溢价率，鲁棒优先）

- 池子过滤（每交易日重算）：上市 ≥ 20 个交易日、`close` 在 95~125 之间、日成交额 ≥ 500 万元、信用评级 ≥ AA-、发行规模 ≥ 2 亿元；
- 打分：`score = close`（越低越好），若同分用正股 20 日动量降序（动量取不到则排后）；
- 取最低的 20 只等权，单只上限 5%，**每周**第一个交易日收盘调仓。

### 候选 B：价格 + 转股溢价率近似（进攻优先）

- 同一过滤条件，但打分改为双低：`score = close + 转股溢价率 × 100`；
- **溢价率必须自己算**：`转股价值 = 100 / 转股价 × 正股收盘价`，`溢价率 = close / 转股价值 - 1`。
  - 转股价用 `bond_zh_cov()` 里的**当期值**，正股收盘价用 `stock_zh_a_hist(symbol=正股代码, adjust="")`；
  - ⚠️ 这是**近似**：转股价会因分红/送股/下修变动，用当期值回溯历史会失真（分红影响 1~3%，下修影响可达 30%）。**必须在报告里披露这个偏差的方向与量级**，并说明它更可能高估还是低估收益；
- 取双低值最低的 15 只等权，每周调仓。

### 加分（可选，别牺牲主线）

- 两套候选取交集（同时满足低价与低溢价），看是否更稳；
- 加换手缓冲：新债进入前必须优于在持债若干名次，压住周频换手成本。

## 3. 红线（A 股可转债特有的坑，违反即作废）

这些不是"最佳实践"，是**会让回测结果系统性虚高**的硬错误：

1. **不许只用当前在市债**。必须用 `bond_zh_cov()` 全表（含退市）逐只拉历史。只拉在市债 = 幸存者偏差，年化会虚高 10 个百分点以上。
2. **强赎必须规避**。已触发强赎的债，价格会从 130+ 向 100 收敛（-20% 以上），且之后停止交易。拿不到强赎公告，就用规则代理：**`close ≥ 130` 的债一律不进池；持有中触及 130 的，下一调仓日必须剔除**。在报告里说明这是规则代理，不是公告驱动。
3. **违约必须认亏，不许美化**。`123015`（蓝盾转债）末价 **26.9** 是真实存在的样本。日线停止交易后，必须按**最后收盘价**清仓，不许假设按面值兑付、不许前向填充价格、不许"最后一天按 100 卖出"。
4. **信用过滤**：评级 A+ 及以下剔除；正股 ST/*ST 剔除；发行规模 < 2 亿元剔除；日成交额 < 500 万元剔除（流动性）。
5. **上市初期剔除**：上市 < 20 个交易日不进池（新债上市首日 130+ 是常态，价格是噪音不是价值）。
6. **只许用日线收盘价成交**。转债 T+0 且无涨跌停（有临停），但**不许**用日内价格、不许假设盘中按某价成交，否则回测不可实现。
7. **不许改 `qs/engine.py`**，不许加杠杆（权重行和 ≤ 1），不许改已有策略默认参数。
8. **不许硬编码收益、不许按日期打补丁**（`if date > '2021-03-01': ...` 这类）。
9. **OOS 只跑一次**，跑完不改参数。

## 4. 验收门槛

主口径：单边成本 **万 5**，周频调仓，起点 2018-01-01。

| 指标 | 及格 | 优秀 |
|---|---:|---:|
| 全样本年化 | ≥ 15.0% | ≥ 22.0% |
| OOS 年化（2023 起） | ≥ 8.0% | ≥ 15.0% |
| 夏普 | ≥ 1.00 | ≥ 1.40 |
| 最大回撤 | ≥ -20% | ≥ -14% |
| 卡玛 | ≥ 0.75 | ≥ 1.20 |
| 年化双边换手 | ≤ 900% | ≤ 500% |
| 千 2 成本年化 | > 5% | ≥ 12% |
| 单只平均权重 | ≤ 5% | ≤ 4% |
| 2018 年以来**每一年** | 不为负 | — |

最后一行是转债策略的关键：它的卖点是"跌不深"，如果某一年亏 15%，说明信用/强赎过滤失效了，收益再高也不算达标。

## 6. 数据工程要求（这部分不做对，后面全白干）

1. **拉数脚本独立**：`research/cb_fetch.py`，逐只拉日线 → `data/cb/<code>.parquet`，字段 `date/open/high/low/close/volume`；
2. **必须支持断点续跑**（`--resume`，已存在且行数 > 0 的跳过）、**必须分批**（默认 100 只/批）、**必须有心跳日志**（每批打印进度 + 已用时间 + 失败数）；
3. **失败不许静默跳过**：失败清单写 `data/cb/_failed.txt`，并在勘测报告里报数。静默跳过 = 池子残缺 = 结果不可信；
4. **预计耗时**：1066 只 × 1.4s ≈ 25 分钟，属正常，不要以为卡死。单只超时设 30s，重试 2 次；
5. 缓存命中优先，报告复现时不许联网（测试要能断网跑）；
6. 全程 `no_proxy='*' NO_PROXY='*'`。

## 11. 反模式警告

- 只拉在市债 → 幸存者偏差，最常见也最致命；
- 把 `close` 当成"净价"却忘了全价含利息 → 收益口径错（用交易价即可，别自己加应计利息）；
- 强赎公告拿不到就假装不存在 → 单笔 -20% 会吃掉整年 alpha；
- 拿当日 `bond_cov_comparison` 的溢价率去回填历史 → 严重未来函数；
- 周频调仓但不算成本 → 900% 换手会把收益磨光；
- 只报 2019-2021（转债大牛市）→ cherry-picking。

**如果跑完发现达不到 15%**：照实写。可转债 2023-2024 经历了估值系统性压缩（杀溢价），如果 OOS 只有 5%，那是市场变了，不是策略写错了。请在报告里把"IS 期收益中有多少来自估值抬升（转股溢价率中位数变化）"拆出来讲清楚——这个归因比多争 3 个百分点更有价值。
