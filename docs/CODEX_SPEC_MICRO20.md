# 施工规格：A 股微盘策略（目标年化 20%–30%）

> 版本：2026-11-08　·　给 Codex 执行
> 前情：ETF 月度轮动 12.23%（p=0.54）、主板低波+动量 4.24%（p=0.075）、可转债指数 5.4%——三条路已证伪。
> 本规格是**最后一条可能触及 20% 的路线**：微盘 / 小市值。它成立的前提是「敢承担 -40% 回撤 + 极小容量」，如果你不接受，请直接停手，不要为了跑通而放宽约束。

## 0. 先读这一节：本次三条铁律（上一轮的教训）

上一轮主板低波策略失败的结构性原因是：**流动性下限（日均成交额 ≥2000 万、取 30–80 分位）把微盘整段剔掉了**——而 A 股 20%+ 的历史收益恰恰集中在这一段。所以本规格：

1. **不许用流动性下限剔除微盘**。允许设一个极低的可交易门槛（日均成交额 ≥ 500 万元），但禁止用分位数筛选把最小市值段排除。
2. **基准必须是同市值段等权组合**，不是沪深 300。用沪深 300 做基准，任何微盘策略都会"赢"，那是 size beta 不是 alpha。
3. **必须报告制度分段结果**。2024 年「国九条」+ 退市从严之后，壳价值基本消失，微盘的定价逻辑变了。如果收益只在 2015–2023 成立，必须明说。

### 2.1 历史市值怎么办 —— 用换手率反推（已实测，误差 <2%）

```
流通市值(t) ≈ 成交额(t) / (换手率(t) / 100)
```

实测校验（2026-11-06 当日）：

| 代码 | 反推 | 快照 | 偏差 |
|---|---:|---:|---:|
| 300181 佐力药业 | 75.5 亿 | 75.4 亿 | +0.1% |
| 600519 贵州茅台 | 18,233.9 亿 | 18,163.7 亿 | +0.4% |
| 000001 平安银行 | 2,267.4 亿 | 2,291.8 亿 | -1.1% |
| 301159 三维天地 | 16.1 亿 | 15.9 亿 | +1.5% |
| 688981 中芯国际 | 2,192.0 亿 | 2,218.7 亿 | -1.2% |

**精度足够做市值分位排序**（我们要排的是"最小 400 只"，1.5% 误差不影响）。注意三点：
- 换手率 = 0 或缺失的交易日必须记为缺失，**不许插值**
- 除权日当天由 `成交额/换手率` 反推的是**除权后**流通市值，与价格一致，不要额外调整
- 上市首日、停牌复牌首日的换手率异常值要剔除（<0.01% 或 >80%）

**不许用当前流通市值快照回填历史**——那是典型未来函数。

## 4. 微盘独有的四个坑（必须写进报告）

### 4.1 流动性螺旋：跌停买不到、跌停卖不掉

微盘踩踏时连续跌停，卖单排队出不去。必须：
- 触及跌停 **阻断卖出**（持仓顺延到下一个可成交日，期间按收盘价估值，不许假设卖出成功）
- 触及涨停 **阻断买入**
- 停牌不可成交，持仓按最后可核验收盘价估值
- 卖出订单可跨日顺延，买入订单 3 日未成交取消

### 4.2 五段极端行情必须单独列出策略表现

| 区间 | 事件 |
|---|---|
| 2015-06 ~ 2016-01 | 三轮股灾 + 熔断 |
| 2017 全年 | 小盘杀估值（大盘蓝筹单边强） |
| 2021-02 ~ 2021-03 | 抱团切换，小盘急跌 |
| 2024-01 ~ 2024-02 | 微盘流动性踩踏（雪球敲入 + 量化 DMA 去杠杆） |
| 2024-04 起 | 新「国九条」+ 退市从严，壳价值重定价 |

要求：给出策略在上述每段的**区间收益 vs 同市值基准**，任何一段跑输基准超过 10 个百分点都要单独解释。

### 4.3 幸存者偏差的量化

必须跑两套账本：
- **全历史池**（含退市，退市按最后可核验价清算；另做零回收压力）
- **仅存续池**（只用今天还在的股票）

把两者年化差写进报告。上一轮这个差是 -0.83 个百分点（主板），微盘这个差会大得多——**如果差值超过 5 个百分点，说明策略收益有相当部分来自"只买活下来的公司"，必须明说**。

### 4.4 制度变更的分段

2024 年之后退市节奏加快、壳价值消失。必须：
- 分别报告 2015–2020、2021–2023、2024–2026 三段年化
- 若只有前两段达标、第三段失效，结论必须写成「该策略适用于旧制度环境，当前已失效」，不许只报全样本。

## 11. 一句实话

微盘的 20%+ 不是"挖掘出来的 alpha"，本质是**承担了三类别人不愿承担的风险**：流动性折价、退市归零的尾部风险、以及踩踏时的无法退出。这份规格把这三类风险全部量化（零回收压力、跌停不可卖、容量 10 分位），所以你拿到的数字会是"扣掉这些代价之后还剩多少"。

如果最后落在 15% 且回撤 -45%，那也是一个可以据以决策的真实答案——**比一个 30% 但不可执行的曲线有价值得多**。
