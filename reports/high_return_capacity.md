# high_return｜容量与三因子审计

沿用已冻结的候选 A：120 日动量、前 3、月度、逆波动权重。重放净值与原归档逐日核对。容量使用 ETF 缓存的人民币成交额，不以成交量代替。原引擎按固定目标权重计算日收益，正式调仓间恢复权重的隐含成交未记费或计入订单；容量只审计现有账本的持仓与正式调仓，未增加参与率撮合、涨跌停或滑点假设。2016-01-01 非交易日现金锚点仅用于净值与归因，不计容量日数。A 股三因子对跨境、商品和债券 ETF 的解释能力有限。

## 容量（V7）

按 5% × 前一交易日可得的 20 日 ADV ÷ 权重逐日计算。实际持仓中先取 ADV 最低 25 只（不足时取全部），再按实际权重取最小容量；订单取参与率裁切前的绝对计划订单权重。空仓日持仓容量记零，无计划订单日的订单容量留空。逐日取瓶颈后计算分位数。

## 收益归因（V8）

与 micro_cap 使用同一全历史 A 股行情面板及同一公式：市场为股票等权日收益；市值为前一交易日流通市值最低减最高五分位；动量为截至前一交易日的 20 日动量最高减最低五分位。仅要求当日收益与前日市值有限，分位数和缺失值处理完全沿用模板，不叠加策略的选股、状态、流动性或正动量过滤。因子为诊断基准，不是可交易组合。载荷仅用截至 2021-12-31 的 IS 毛对数收益进行无截距日频拟合，随后冻结。

| 分量 | 累计对数贡献 | 占净收益 |
| --- | --- | --- |
| 市场 beta | 31.79% | 44.56% |
| 市值因子 | -67.04% | -93.97% |
| 其他风格（20 日动量） | 2.40% | 3.36% |
| 选股残差 | 108.33% | 151.85% |
| 交易摩擦 | -4.13% | -5.79% |

| 因子 | IS 载荷 | 原始日收益累计和 | 载荷 × 原始累计和 |
| --- | --- | --- | --- |
| 市场 | 0.402755 | 78.93% | 31.79% |
| 市值 | -0.312177 | 214.76% | -67.04% |
| 20 日动量 | 0.042587 | 56.24% | 2.40% |

原始因子列为日收益算术累计和，不是复合收益；乘固定载荷后为累计对数贡献。选股残差为同一成交路径毛对数收益减三因子贡献，包含未识别暴露；摩擦为每日净毛对数差。五项未舍入之和为累计净对数收益 71.34%，负残差和摩擦可使因子占比超过 100%。逐日因子见 [三因子序列](../results/high_return_factors.csv)。

### 复现

依赖已有 ETF/股票缓存、micro_cap 使用的本地 Tushare 归档和原净值 CSV；不重选参数、不覆盖原净值与权重。报告生成额外需要 pyarrow 读取 parquet，版本约束沿用 requirements.txt。

```bash
uv run --with pytest --with numpy --with pandas --with pyarrow python -m research.high_return_capacity
uv run --with pytest --with numpy --with pandas python -m pytest tests/ -q
```
